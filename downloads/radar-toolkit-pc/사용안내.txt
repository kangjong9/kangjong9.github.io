레이더 툴킷 PC 1.0.1

Windows 10/11 64비트용. ZIP 전체를 폴더에 풀고 RadarToolkitPC.exe를 실행하세요.
EXE와 _internal 폴더를 함께 유지하세요. Python 별도 설치는 필요 없습니다.

지연 계산: 실제 거리와 VRM 입력 → TDELAY 계산 → 결과 복사.
북방위: 방위차 0~360° 입력 → + 또는 − 선택 → 결과 자동 계산·복사.
북방위 역산: 역산 모드에서 정렬값 0~32768 입력 → +/− 선택 → 방위차(°) 계산. 0/32768은 원래 0°와 360°를 구분할 수 없습니다. 반올림한 결과를 역산하면 근사값입니다.
지연 역산: 역산 모드에서 TDELAY 입력 → 실제 거리−VRM의 거리차(m) 계산. 실제 거리는 VRM이 있어야 구할 수 있으며 이 화면은 거리차만 표시합니다.
송신: 멀티캐스트 IP·포트·로컬 IPv4·TTL·MTU·개수·간격 설정 → 송신 시작.
수신: 멀티캐스트 IP·포트·로컬 IPv4 설정 → 수신 시작. 송신과 독립 실행·중지됩니다.
0.0.0.0 인터페이스는 Windows 기본 네트워크를 사용합니다. 원하는 로컬 IPv4를 선택할 수 있습니다.
송신 완료 후 수신은 계속 유지됩니다. 앱을 닫으면 둘 다 종료됩니다.
시험 MTU는 실제 네트워크 MTU 변경/측정이 아닙니다. 자체 루프백 수신은 상대 기기 도달 증거가 아닙니다.
방화벽·공유기 멀티캐스트 정책에 따라 송수신이 제한될 수 있습니다. 시스템 설정은 앱이 변경하지 않습니다.

업데이트: 시작 시 자동 확인하며 상단 버튼으로 수동 확인할 수 있습니다. 새 버전 ZIP 다운로드 후 크기·SHA256 검증을 수행합니다. 현재 앱을 종료하고 새 폴더에 압축 해제하여 실행하세요.
새 버전 파일을 자동 덮어쓰지 않습니다. 실패하면 현재 버전을 계속 사용할 수 있습니다.

현재 PC에서 계산·입력·GUI 실행/종료·모의 네트워크 및 패키징 검증. Windows 10 별도 PC, 실제 장비·Wi-Fi 송수신, 향후 버전 교체는 미검증입니다.
