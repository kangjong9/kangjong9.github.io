한걸음 17 · AI 통역사 대면 분할 / 1.0.20-training.26

AI 통역사 → 상대방 언어(위) / 내 언어(아래) 선택 → 원하는 쪽의 말하기 버튼.
상대방 화면은 기본 180도 반전됩니다. 중앙 또는 상단에서 반전과 1인/대면 뷰를 전환합니다.
언어 교환은 현재 통역을 정지한 뒤 언어와 표시 문장을 함께 바꿉니다.
자동 전환 ON: 센서를 지원하고 권한을 허용한 환경에서 평평하게 놓으면 대면 뷰, 세우면 1인 뷰.
센서를 지원하지 않으면 수동 전환을 이용하세요. 센서는 기본 OFF입니다.
번역 듣기/복사는 각 영역에서 사용합니다. 복사 권한이 없는 환경에서는 문장을 길게 누르세요.

자동 통역 버튼은 선택한 두 언어를 기준으로 마이크 방향을 자동 선택합니다.
Android 14 이상과 언어 판별/전환을 지원하는 음성 인식기가 필요합니다. 사람의 신원을 판별하지 않습니다.
최대 25초까지 듣되 말끝 무음을 기준으로 나눕니다. 실제 종료 시점은 음성 인식기에도 영향을 받습니다.
입력 중 번역 자막을 갱신하고 마지막에 문장 전체를 보정합니다. 음성은 최종 문장을 읽습니다.
원문 최소 24px·번역 최소 28px, 밝은 청록 화면, LLM 메뉴 16px 이상/버튼 48px 이상을 적용했습니다.
전체 화면 자동 축소 대신 실제 화면 폭에 맞춰 배치하고 필요한 본문을 스크롤합니다.
현재 선택한 음성을 유지하면서 Qwen 첫 합성 구간과 불필요한 재생 대기를 줄였습니다.
PC 모의 음성 흐름·9가지 화면 크기 및 맞춤훈련 APK 설치/실기 화면을 검증합니다.
실제 사람 발화의 자동 언어 판별 정확도와 음성 시작 지연 수치는 아직 측정하지 않았습니다.

아래는 기존 기능 안내입니다. 과거 버전의 설치·검증 내용은 이번 버전의 검증을 뜻하지 않습니다.

한걸음 17 · 맞춤훈련 / 1.0.16-training.21

기존 한걸음과 별도 설치되는 앱입니다. 기존 앱과 학습 데이터는 그대로 유지됩니다.
Android 8 이상, arm64 기기용입니다. 설치되어 있는 17번 앱 위에 업데이트하세요.

AI 튜터 → 감정 보이스 → 한국어/영어 → 목소리 선택 → 샘플 듣기.
한국어 22종과 영어 22종은 각각 다른 성격·말투·발성을 지시한 AI 합성 보이스입니다.
각 언어 남녀 1~10번은 공개, 남녀 11번은 기존 관리자 잠금 해제 후 표시됩니다.
실제 배우나 특정인의 목소리를 복제하지 않았습니다.
기존 직업 보이스·Piper·Melo·Kokoro 등도 유지됩니다.

학습 주제의 오늘의 뉴스는 드롭다운에서 기사를 고르고 한 화면에서 회화를 시작합니다.
AI 통역사는 한국어·영어·프랑스어·중국어·일본어·스페인어·러시아어 조합을 지원합니다. 통역사는 앱 안 전체 화면으로 표시되며 우측 하단 뒤로가기로 닫습니다.
Google ML Kit 번역 언어 팩을 처음 사용할 때 내려받아야 합니다. 문장 단위로 이어서 통역하며 전체 동시 통역은 아닙니다.
번역은 기기에서 처리하고, 음성 인식은 Android 음성 인식 기능을 사용합니다. 인터넷 연결과 기기 설정에 따라 인식 기능이 달라질 수 있습니다. 이번 업데이트(1.0.16)는 앱 내부 처리 효율 개선이며 화면과 기능은 같습니다.
번역 결과에는 Google ML Kit/Google Translate 기반 번역이 포함될 수 있습니다. Google은 번역의 정확성·신뢰성 및 특정 목적 적합성에 관한 보증을 제공하지 않습니다.

샘플은 앱에 들어 있어 바로 들을 수 있습니다. 실제 새 대사는 기기에서 합성합니다.
처음 실제 감정 대사를 합성하면 약 1.5GB 모델을 다운로드합니다. Wi-Fi와 충분한 저장 공간을 권장합니다.
무료 로컬 엔진이며 API 키는 필요 없습니다. 처리 시간과 메모리 사용량이 큽니다.
휴대폰에 따라 느리거나 사용할 수 없을 수 있으므로 기존 직업 보이스로 돌아갈 수 있습니다.
미리듣기와 실제 대사는 서로 다른 실행 형식의 같은 모델 계열로, 음색·감정에 차이가 날 수 있습니다.
실제 Android 감정 대사 합성의 속도와 감정 품질, 통역 언어 팩 다운로드와 통역 음성 입출력은 이번 최종본에서 실기 검증하지 못했습니다. 앱 업데이트 설치와 버전은 연결된 스마트폰에서 확인했습니다.

앱이 시작할 때 새 버전을 확인하고 안내합니다. 다운로드 후 Android의 설치 확인을 눌러야 합니다.
자동 확인과 무인 설치는 다릅니다. 기존 앱의 업데이트 채널은 변경하지 않았습니다.
