[한걸음V1.0 Exile · 앱 사용 가이드]

1. 앱 소개
- 명칭: 한걸음V1.0 Exile (Hangeoreum V1.0 Exile)
- 세계관: 안드로메다 은하에서 머나먼 지구로 유배 온 AI '엑자일(Exile)'이 지구인 사용자를 외국어 마스터로 육성하여 안드로메다로 귀환하고자 하는 50레벨 탈출 프로젝트!
- 지원 언어: 프랑스어(Français), 중국어(中文), 일본어(日本語)
- 3대 플랫폼: Android 8.0 이상 스마트폰 APK / 모던 웹 브라우저 시안 체험

2. 핵심 5대 보완 기능
(1) 초고시인성 모바일 UI
- 폰트 크기 대폭 확대: 타깃 외국어 문장 28~32px 볼드, 한국어 문맥 18~20px, 발음 기호 16px
- 쫀득한 3D 버튼 및 52px 이상 대형 터치 타깃으로 가독성과 조작감 극대화

(2) AI API 연동 설정칸 (⚙️)
- 상단 헤더 우측 [⚙️] 버튼으로 Google Gemini / OpenAI / Anthropic Claude / Custom API 연동 지원
- API Key 입력, 모델명 선택, [연결 테스트] 및 안전한 로컬 저장
- 연동 시: 일상 대화 맞춤 문장 실시간 생성 및 AI 원어민 심층 발음 코칭
- 미연동 시: 내장된 6대 테마 x 50레벨 고품질 오프라인 엔진으로 100% 정상 작동

(3) 100% 무음 방지 3중 원어민 음성 Fallback
- 1순위: Google Translate TTS 고음질 오디오 스트리밍 (원어민 발음 100% 보장)
- 2순위: Android Native TextToSpeech 하이브리드 브릿지
- 3순위: HTML5 Web Speech API
- 5대 엑자일 음성 프리셋 (여왕, 수호대장, 요정, 사이버봇, 사자) 선택 및 유지

(4) 4단계 섀도잉 루프 (Shadowing 4-Round Loop) & 음성 분석 통과 가드
- Round 1: [기준 예문] 최초 듣고 따라하기
- Round 2: [변형 1] 주어/인칭 변경 슬롯 치환 발화
- Round 3: [변형 2] 상황/장소/부사 변경 발화
- Round 4: [변형 3] 심화 실전 응용 문장 발화
- [🎙️ 마이크로 말하기] 클릭 시 실제 마이크 음성을 수신하여 정확도 점수(0~100점) 실시간 산출
- 엄격한 게이트키퍼 통과 가드: 70점 이상 달성 시에만 [다음 단계] 버튼이 열리며, 70점 미만 시 절대 통과할 수 없음!

(5) 안드로메다 귀요미 엑자일 캐릭터 앱 아이콘
- 우주 은하수 배경, 반짝이는 더듬이 별, 초롱초롱한 눈망울과 방긋 웃는 미소를 담은 고화질 벡터 아이콘 탑재
