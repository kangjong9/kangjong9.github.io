[한걸음V1.0 Exile · 앱 사용 가이드]

1. 앱 소개
- 명칭: 한걸음V1.0 Exile (Hangeoreum V1.0 Exile)
- 세계관: 안드로메다 은하에서 머나먼 지구로 유배 온 AI '엑자일(Exile)'이 지구인 사용자를 외국어 마스터로 육성하여 안드로메다로 귀환하고자 하는 50레벨 탈출 프로젝트!
- 지원 언어(5개): 프랑스어(Français), 중국어(中文), 일본어(日本語), 영어(English), 스페인어(Español)
- 배울 언어는 처음 시작할 때 고릅니다. 수업 화면에는 언어 변경 버튼이 없습니다.
- 설치: Android 8 이상. 음성 재생에는 인터넷 연결이 필요합니다.

2. 입문 Lv.0 — 문자 배우기 (신규)
- 처음 시작할 때 엑자일의 능력 테스트에 "문자를 읽을 수 있나요?" 질문이 있습니다. '전혀 몰라요'를 고르면 무조건 Lv.0 입문부터 시작합니다.
- 언어별 문자: 일본어 히라가나·가타카나 / 중국어 병음·성조·기본 한자 / 프랑스어·영어·스페인어 알파벳 읽기 규칙
- 단원마다 글자를 먼저 익히고, 그 단원까지 배운 글자로만 만든 단어를 읽어 봅니다.
- 글자도 단어도 세 번씩 반복합니다: 매 글자·단어마다 엑자일이 먼저 원어민 발음으로 시범을 보이고, 사용자가 따라 읽습니다. 1회차는 글자와 한글 읽기를 같이 보고, 2·3회차는 순서를 섞어 한글 없이 글자만 보며(중국어 한자·병음 등 그 언어 표기는 그대로) 따라 읽은 뒤 '정답 확인'으로 맞춰 봅니다. '헷갈려요'를 누른 글자는 그 회차 끝에 한 번 더 나옵니다.
- 모든 단원을 마치면 축하와 함께 Lv.1로 올라갑니다. 레벨 버튼의 'T0:문자'로 언제든 다시 복습할 수 있습니다.

3. 50레벨 × 5세트 커리큘럼 (리뉴얼)
- 다섯 구간으로 난이도가 오르며, 구간 안에서도 레벨마다 조금씩 어려워집니다.
  · 1~10 기초 생존 청크 · 11~20 기본 문장 · 21~30 시제·이유 확장 · 31~40 실전 의사소통 · 41~50 고급 뉘앙스
- 각 레벨은 5세트를 반복하며, 세트마다 다른 장면·다른 표현을 배웁니다. 세트 하나는 4라운드(핵심 청크 → 기본 문장 → 맥락 확장 → 실전 발화)입니다.
- 1세트는 앱에 들어 있는 기본 세트입니다. 2~5세트는 Gemini AI가 앞 세트의 맥락을 이어 새 주제로 만듭니다(데일리 체크인에서 한 말도 반영).
  Gemini 키가 없으면 같은 구간의 다른 내장 세트로 진행하므로, 키 없이도 레벨 안 5세트의 내용은 서로 다릅니다.
- 1~10레벨은 처음 시작한 장면의 맥락이 끝까지 이어집니다. 예: 첫 인사로 시작했다면 "어떻게 지냈어?" → "이름이 뭐야?" → 출신 → 하는 일처럼 같은 만남 안에서 대화가 이어집니다. (Gemini 키가 있을 때 적용, 11레벨부터는 새 장면으로 전환)
- 이미 배운 표현은 다시 나오지 않도록 관리합니다.
- 레벨이 열리면 문장 옆에 장면 그림(일러스트)이 나타납니다.
- 세트를 마치면 반짝 효과와 함께 칭찬하고, 레벨업 때는 축하 카드와 함께 엑자일이 축하·응원 메시지를 말해 줍니다.
- 50레벨 5세트를 마치면 실전 롤플레잉이 열립니다. 대화 상대를 프리셋 6명 중에서 고르거나 이름·역할·성격·성별로 직접 만들 수 있습니다.
  상대는 고른 성별의 원어민 목소리로 말하고, Gemini 키가 있으면 대화 흐름에 맞춰 자유롭게 답합니다.

4. Gemini API (키 하나로 모두 사용)
- 설정에 Gemini API 키 하나만 넣으면 됩니다.
- 음성(TTS)은 TTS 전용 모델만 호출합니다.
- 세트 생성·대화·코칭 같은 글 생성은 3.8 Flash부터 3.7 → 3.6 → 3.5 → 3.0 → 2.5 → 2.0 Flash, 이어서 Lite 계열 순서로 자동 전환합니다.
- 키로 실제 사용 가능한 모델을 하루 한 번 조회해 최신 모델부터 쓰고, 없는 모델은 다시 기다리지 않습니다. 다음 세트 2개는 미리 만들어 두어 넘어갈 때 기다림을 줄입니다.

5. 누리 보이스(Nuri Voice) — 4대 음성 엔진
- 오픈화면의 음성 탭과 설정의 '누리 보이스 · 4대 음성 엔진 설정'은 같은 선택을 공유합니다.
- 기본 목소리: Edge '선희'(차분한 한국어 여성, API 키 불필요).
- (1) Edge 신경망 음성 · 23종 · 키 불필요
- (2) Gemini 사람 음성 · 40종 (+ 관리자 해금 시 히든 4종 = 44종) · Gemini API 키 필요
- (3) ElevenLabs · 16종 · ElevenLabs API 키 필요 (기본: 벨라)
- (4) Kokoro · 28종 · 폰 안에서 직접 합성(영어 전용, 원래 지원 범위 그대로: 한글은 번역하지 않고 읽지 않으며 문장 속 원어 부분만 그대로 읽음). 처음 사용 시 모델 약 92MB를 한 번 내려받습니다.
- 엑자일의 한국어 대사는 고른 목소리로, 수업의 외국어 문장은 원어민 신경망 목소리(Edge, 키 불필요)로 나옵니다.
  설정의 '강사 성별'에서 여성(Denise·Nanami·Xiaoxiao·Jenny·Elvira) / 남성(Henri·Keita·Yunxi·Guy·Alvaro)을 고릅니다.
- 언제나 한 목소리만 나옵니다. 고른 엔진이 실패하면 다른 음성으로 대신 읽지 않고 멈추며 화면에 안내합니다.

6. 화면·효과
- 글씨를 키우고 흐린 글자색을 진하게 바꿔 잘 보이게 했습니다.
- 마이크로 말하는 동안 화면 아래에 파동 애니메이션이 나타납니다.
- 상단 '처음으로'를 누르면 오픈화면부터 다시 시작합니다.
- 효과음: 기본 효과음(무전 시작/수신, 정답 코인, 오답, 클릭)에 개성 효과음 12종이 추가되었습니다.

  설정의 효과음 항목마다 원하는 소리로 바꿀 수 있습니다.

7. 4라운드 섀도잉 & 60점 통과 기준
- 원어민 발음을 듣고 따라 말하면 발음 일치도를 채점합니다. 60점 이상이면 합격, 다음 라운드로 자동 진행됩니다.
