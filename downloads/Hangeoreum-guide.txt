# 한걸음 0.2.0-dev · Android 초안

Android 8 이상 기기에 `한걸음-0.2.0-dev.apk`를 옮겨 설치하세요. 앱 이름은 한걸음입니다. 처음 설치할 때 해당 파일 앱의 ‘알 수 없는 앱 설치’ 허용이 필요할 수 있습니다. 공개 스토어 배포본이 아닌 개발용 서명 초안입니다.

1. 프랑스어·중국어·일본어 중 공부할 언어를 선택합니다. 각 언어는 별도 과정과 기록을 갖습니다.
2. 1분·5분·15분 루틴을 고르고 ‘이어서 연습하기’를 누릅니다. 각각 1회·2회·4회 표현 연습을 제공합니다. 시간은 목표 시간이며 AI 응답 지연이나 재연습을 강제로 잘라 내지 않습니다.
3. 그림과 뜻을 보고 ‘기초 단어’ 또는 ‘짧은 회화’를 선택합니다. ‘표현 듣기’로 듣고 따라 말합니다. 기기의 언어 TTS 데이터가 필요하며, 전문 성우 녹음이 아닙니다.
4. 내 목소리를 녹음한 뒤 ‘내 녹음 듣기’로 확인합니다. 최대 30초 후 자동 종료됩니다. 화면 이탈·앱 백그라운드 전환 시 진행 중 녹음은 중단됩니다.
5. ‘내 발음 분석’을 누르면 녹음이 Gemini로 전송되고 들린 내용에 기반한 연습 조언을 받습니다. AI 조언은 정밀 음성학 측정이나 합격 보장이 아닙니다. 잡음·무음에서는 다시 녹음하세요.
6. 매 단원에서 주제를 선택하거나 직접 적고 Gemini와 회화할 수 있습니다. 글 또는 음성으로 답합니다. 1분 루틴에서도 ‘조금 더: 주제 회화도 해 보기’로 연결됩니다.
7. 연습을 마치면 선택 언어의 복습 기록에 남습니다. 연습 완료나 시간이 지났다는 이유로 다음 단계가 열리지는 않습니다.

## AI 키 설정
오른쪽 위 설정 → Gemini API 키 저장 → 전송 고지 확인 후 저장. 저장 성공 메시지와 ‘저장되어 있음’ 상태를 확인할 수 있습니다. 키는 Android Keystore로 암호화해 기기에 저장하며 화면이나 로그에 재출력하지 않습니다.

결제가 연결되지 않은 무료 프로젝트 키를 사용하세요. 앱은 계정의 과금 연결 여부를 확인할 수 없습니다. 회화/분석을 누를 때 글·음성이 Google에 전송되며, 무료 티어 정책에 따라 서비스 개선에 사용될 수 있습니다. 앱에 제작자의 키는 포함하지 않았습니다. 연결 모델은 Gemini 3.8 Flash이며 사용할 수 없는 계정·쿼터 초과·네트워크 오류는 표시합니다. 다른 모델로 몰래 바꾸지 않습니다.

## 전체 단계 확인용 비밀번호
설정 → 관리자 비밀번호 설정에서 12자 이상의 비밀번호를 직접 정합니다. 화면을 3초 안에 5번 가볍게 두드리면 인증창이 열립니다. 인증 후 15분 동안 3개 언어의 모든 단원을 볼 수 있으며, 테스트 중 실제 진도와 복습 기록은 바뀌지 않습니다. 위쪽 배너의 ‘종료’를 누르면 일반 학습으로 돌아옵니다. 비밀번호 복구는 초안에 없으므로 기억할 수 있게 관리해 주세요.

## 초안의 범위
- 언어별 10개 단원, 총 30개 단원과 60개 문장·30개 단어. 전체 교육과정 분량을 완성한 상태는 아닙니다.
- 정식 승급 평가는 교육·음성 평가 기준 검수 전이라 잠겨 있습니다. 일반 학습은 언어별 1단계, 소유자 테스트는 인증 후 전 단계 체험입니다.
- API 없이도 듣기·그림·녹음 재생을 연습하고 기록할 수 있습니다. AI 피드백·회화에는 본인 API 키가 필요합니다.
- 화면 시안 HTML은 PC에서 바로 열 수 있지만 실제 마이크·Gemini·보안 저장은 Android 앱에서만 사용합니다.
- APK 빌드·정적 검사·브라우저 동작을 확인했습니다. 실제 휴대폰 마이크/TTS/키 저장 및 실제 학습자의 Gemini 발음 피드백 품질은 아직 실기기 검증 전입니다.
- 삭제/재설치 시 기기 기록과 키가 사라질 수 있습니다. 계정 동기화나 서버 백업은 제공하지 않습니다.

## 0.2 추가 기능
기존 앱을 삭제하지 않고 업데이트 설치하세요. 언어별 복습 간격, 마지막 연습 위치 이어하기, 새 녹음의 영역별 AI 평가 연습을 추가했습니다. 영역별 평가는 정식 승급 증거가 아니며 실기기·실제 음성 평가 품질은 미검증입니다.
