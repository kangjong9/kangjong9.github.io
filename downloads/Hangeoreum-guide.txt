[한걸음V1.0 Exile · 앱 사용 가이드]

1. 앱 소개
- 명칭: 한걸음V1.0 Exile (Hangeoreum V1.0 Exile)
- 세계관: 안드로메다 은하에서 머나먼 지구로 유배 온 AI '엑자일(Exile)'이 지구인 사용자를 외국어 마스터로 육성하여 안드로메다로 귀환하고자 하는 50레벨 탈출 프로젝트!
- 지원 언어: 프랑스어(Français), 중국어(中文), 일본어(日本語)
- 설치: Android 8 이상. 음성 재생에는 인터넷 연결이 필요합니다.

2. 누리 보이스(Nuri Voice) — 4대 음성 엔진
- 오픈화면의 음성 탭과 설정의 '누리 보이스 · 4대 음성 엔진 설정'은 같은 선택을 공유합니다. 어디서 고르든 양쪽에 똑같이 적용됩니다.
- 기본 목소리: Edge '선희'(차분한 한국어 여성, API 키 불필요). 앱을 처음 열면 이 목소리로 한 번만 안내합니다.
- (1) Edge 신경망 음성 · 23종 · 키 불필요 (한국어 선희·인준 외 다국어)
- (2) Gemini 사람 음성 · 40종 (+ 관리자 해금 시 히든 4종 = 44종) · Gemini API 키 필요
- (3) ElevenLabs · 16종 · ElevenLabs API 키 필요 (기본: 벨라)
- (4) Kokoro · 7종 · 정해진 영어 샘플 음성만 재생(문장 낭독 아님)
- 엑자일 캐릭터의 한국어 대사는 고른 목소리로, 수업의 외국어 문장은 원어민 신경망 목소리(Edge, 키 불필요)로 나옵니다.
  설정의 '강사 성별'에서 여성(Denise·Nanami·Xiaoxiao) / 남성(Henri·Keita·Yunxi)을 고릅니다.
- 언제나 한 목소리만 나옵니다. 새 문장을 말하거나 엔진·목소리를 바꾸면 재생 중인 음성은 즉시 멈춥니다.
- 고른 엔진이 실패하면(키 없음·연결 실패) 다른 음성으로 대신 읽지 않고 멈추며 화면에 안내합니다.
- API 키는 설정에서 직접 입력하며 이 기기 안에만 저장됩니다.

3. 상황별 효과음 (SFX)
- 음성 입력 시작 전: intercom_sent.mp3 (수신 대기 챠임)
- 음성 입력 완료 시: intercom_received.mp3 (인식 완료 챠임)
- 틀렸을 때: wrong.mp3 (오답 사운드)
- 맞췄을 때: correct.mp3 + combo_01.mp3 (정답 및 콤보 사운드)
- 레벨 마스터 완료 시: complete.mp3 (팡파르)

4. 4단계 섀도잉 루프 & 60점 통과 기준
- Round 1: 기준 예문 듣고 따라하기
- Round 2: 변형 1 (주어/인칭 변경)
- Round 3: 변형 2 (상황/장소 변경)
- Round 4: 변형 3 (심화 응용 문장)
- 발음 일치도 60점 이상이면 합격, 다음 단계로 자동 진행됩니다.
