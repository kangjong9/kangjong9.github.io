VocalMate 0.6.0-dev — 파형·가사·전체 단독 보컬 비교 개발판

Android 8 이상. 기존 앱을 삭제하지 말고 APK를 열어 업데이트하세요.
기존 패키지명·개발 서명 유지, 버전 코드 8→9. 기존 기록·보정값 읽기 유지.
실제 휴대폰 업데이트·데이터 유지 및 음향 실측은 미검증입니다.

이번 변경
1. ‘노래부르기’에서 기준곡 전체를 선택하면 실제 음량 파형이 표시됩니다.
   파형을 눌러 위치 이동, 시작/끝 손잡이 이동, 확대·앞뒤 이동을 제공합니다.
   현재 위치부터 듣기·일시정지·현재 위치를 시작/끝으로 지정할 수 있습니다.
   구간 반복 및 따라 부르기를 연결했습니다. 초 입력은 ‘시간 숫자로 미세 조정’ 안에 있습니다.
2. 가사 LRC/TXT(UTF-8/UTF-16)를 불러오거나 직접 붙여넣습니다.
   LRC 시간가사는 재생 위치에 맞춰 강조하며 가사 줄로 구간을 선택합니다.
   일반 가사는 들으면서 ‘지금 위치 연결’로 줄별 시간을 지정합니다.
   가사 자동 검색·음성인식·자동 생성은 하지 않습니다. 가사는 기기에 저장합니다.
3. 내 가창 전체 파일도 선택하면 두 파일을 전체 분석합니다. 파일당 최대 30분.
   양쪽 모두 반주 없는 단독 보컬일 때 자동 시간 정렬, 음정 차이, 유효 관측 비율,
   자동 구간, A/B 반복, 기술 레슨 이동/구간 복귀, 이전 전체 결과 비교를 제공합니다.
   키 차이는 직접 지정하며 자동 옥타브 보정으로 오차를 숨기지 않습니다.
   시간 대응 편차는 박자 정확도나 기술 점수와 다릅니다.
4. 반주 혼합 파일은 파형·연습 구간만 제공하며 보컬 정답 음정 비교를 하지 않습니다.
   실제 보컬 분리와 혼합곡 정량 비교는 미완료입니다. 두성·믹스 기법 판정도 하지 않습니다.
5. 강사 수강사이트, ‘원본 동영상 열기’, ‘이 강사의 원 강의 사이트’ 버튼을 제거했습니다.
   강사 프로필은 앱 안에서 표시하며 공개 레슨은 앱 내 플레이어로 봅니다.
6. 기존 강사 레슨·오늘 훈련·발성·두성·믹스·선택 녹음·캘리브레이션 유지.

입력은 휴대폰에 내려받은 일반 오디오 파일을 사용하세요. 스트리밍 공급자는 지원하지 않습니다.
원본 파일을 변경/업로드하지 않으며 분석 결과·가사·선택 녹음은 기기에 저장합니다.
선택 녹음은 재생·공유·삭제할 수 있습니다. 전체 분석은 60초에서 자르지 않습니다.
짧은 반복 실습 구간만 1~60초이며 전체 음원 분석과 구분됩니다.

검증: Android 빌드, 변경 관련 JVM60건, UI 모의브리지16그룹, APK 자산/서명 검사.
미검증: 실제 휴대폰 렌더/손잡이 터치, MP3/M4A/WAV 플랫폼 해독·재생·권한,
마이크·녹음/공유·생명주기, 실제 가창 정렬/정확도, 캘리브레이션 실측.
자동검사는 실제 기기 음향 정확도·교육 효과 검증을 대신하지 않습니다.
Gemini Flash/Live는 기존 기능 개발·검증 이후 마지막 단계이며 이번 APK에는 없습니다.
