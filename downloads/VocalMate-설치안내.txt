VocalMate 0.3.0-dev — Android 개발 배포본

설치 파일: VocalMate-0.3.0-dev.apk
Android 8 이상, 개발용 서명 APK입니다.
스마트폰으로 APK를 옮겨 열면 설치/업데이트할 수 있습니다.
기존 11개 디자인 화면에 오프라인 훈련·실제 결과·성장 기록·추천·자체 멜로디 연습을 연결했습니다.
마이크 버튼으로 분석 시작/정지, 목표음 선택, 롱톤·음역대·허밍 훈련을 사용할 수 있습니다.
기존 엔진 상세 화면에서는 기준음 체험 또는 WAV 파일 선택을 사용할 수 있습니다.
WAV: 모노 PCM16/float32, 8–192 kHz, 64 MiB 이하. MP3/스테레오 미지원.
합성 자체 시험/WAV는 스피커 재생 없이 분석합니다. WAV 임시 사본은 종료 후 삭제합니다.
음성 원본은 저장하지 않습니다. 분석 수치와 설정은 기기 안에 저장하며 외부 서버 업로드는 하지 않습니다.
마이페이지 > 앱 설정 · 캘리브레이션에서 실제 측정, CSV 공유, 보정 제안/적용/취소/원복을 사용합니다.
기준음 재생은 이어폰을 권장합니다. 자체 스피커 루프백은 독립 정확도 시험이 아닌 간이 점검입니다.
비브라토는 유효 구간이 충분할 때만 표시하며 성대/호흡 건강 진단을 하지 않습니다.
커뮤니티 서버·상용곡·외부 AI 진단은 출시 미포함입니다.
입력 장치가 바뀌면 정지하며 다시 시작 버튼을 누릅니다.
권한 허용/파일 선택 후 앱 화면으로 돌아오면 분석이 시작됩니다.
WAV/합성 자체 시험 진행 시간은 입력 처리 위치이며 정확도나 지연 측정값이 아닙니다.
정지 후 시험 로그 공유에서 상태별 프레임 집계와 수치 기록을 공유할 수 있습니다.
검출/제외율은 저장된 프레임 집계이며 음정 정확도나 합격률이 아닙니다.
자동검사와 APK 빌드를 수행했습니다. 새 버전 실기/성능/실측 캘리브레이션은 미검증입니다.
후속 실측: 스마트폰에서 개발자 옵션 > USB 디버깅을 허용하고 PC에 USB로 연결하세요.
기존 포터블 Android SDK에서 adb devices -l 확인 후 adb install -r <APK>로 데이터 보존 업데이트합니다.
앱 캘리브레이션에서 외부 기준음을 측정하고 공유한 CSV/요약으로 장치별 오차를 검토합니다.
