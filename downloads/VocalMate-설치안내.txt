VocalMate 0.5.0-dev — 강사 레슨·연습실 우선 제공 개발판

Android 8 이상. 기존 앱을 삭제하지 말고 APK를 열어 업데이트하세요.
기존 패키지명과 개발용 서명을 유지하고 버전 코드를 7에서 8로 올렸습니다.
기존 분석 기록·설정·캘리브레이션을 읽는 호환 코드를 유지했습니다.
실제 휴대폰에서의 업데이트 및 데이터 유지 확인은 아직 수행하지 못했습니다.

이번 버전
- 오늘 훈련: 목표·시간·컨디션에 따른 연습 순서와 수행 기록.
- 레슨·과정: 한국인 강사 9명의 공개 동영상 40개를 주제별로 선택.
  이송희(@vocallesson1533)·버블디아 포함. 프로필·원본 사이트 링크 제공.
  동영상 시청에는 인터넷 연결이 필요하며 시청 여부는 사용자 확인입니다.
- 연습실: 발성·립트릴·허밍·모음·스케일·두성·믹스 연습 진입,
  음 높이·속도·반복 설정, 목표 음정과 실시간 분석, 음별 결과.
  두성·믹스의 발성 기법 자체를 자동 판정하는 기능은 아닙니다.
  높은 음 연습은 같은 입력 경로에서 확인한 편한 음역 기록이 필요합니다.
- 녹음: 사용자가 저장을 켠 연습의 WAV를 기기에 저장, 재생·공유·삭제.
  공유는 사용자가 실행할 때만 진행하며 음성 자동 업로드는 없습니다.
- 캘리브레이션: 독립 메뉴와 바로가기, 기존 측정·설정 유지.
- 메뉴 이동 시 진행 중인 연습·재생을 중지합니다.

노래부르기는 현재 파일을 가져와 1~60초 구간을 재생하고 따라 하는 범위입니다.
원곡 전체와 사용자 가창 전체의 자동 비교·구간별 티칭은 다음 업데이트로 개발합니다.
Gemini Flash/Live는 기존 기능 개발·검증 이후 마지막 단계이며 이번 APK에는 없습니다.

검증: Android 빌드 성공, 변경 관련 JVM 42건, 현재 UI 모의 브리지 14그룹 통과.
APK 자산 원본 일치 및 기존 서명 일치 확인.
미검증: 실제 폰 설치·업데이트, 화면·동영상 청취, 마이크/블루투스/권한,
녹음·공유·백그라운드 동작, 음향 정확도와 캘리브레이션 실측.
동영상의 공개 메타데이터와 임베드 가능 여부는 확인했으나 전체 청취 검수는 미완료입니다.
자동검사 통과가 실제 음향 정확도나 전문 발성 기법 검증을 뜻하지 않습니다.
