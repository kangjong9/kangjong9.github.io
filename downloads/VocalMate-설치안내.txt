VocalMate 0.6.3-dev — 휴대폰 로컬 보컬 추출 개발판

Android 8 이상. 기존 앱 삭제 없이 APK로 업데이트하세요.
기존 패키지와 서명을 유지합니다. 버전 코드 11→12.

노래부르기 → 기준곡/내 가창 전체 선택 → 보컬 추출 → 원하는 위치 미리 듣기
→ 추출본을 비교에 사용 → 두 음원의 단독 보컬 청취 확인 → 전체 분석.
원본 사용으로 돌아갈 수 있습니다. 기존 파형·가사·레슨·사람시범·녹음·캘리브레이션 유지.

원본은 수정하거나 업로드하지 않습니다. 추출은 기기에서 실행하며 모델도 APK에 포함합니다.
파일당 1초~30분, 모노/스테레오 파일을 지원합니다. 처리 중 화면을 유지해 주세요.
메모리 부족·저장 공간 부족·불완전 파일은 안내 후 중지합니다. 취소·메뉴 이동 시 중지합니다.
취소 중 생성된 임시 파일은 정리하고 기존 원본/결과를 보호합니다.
원본 상태에서 추출하거나 같은 음원을 다시 선택해도 기존 비교 결과를 초기화하지 않습니다.

추출은 실험 기능입니다. 반주·코러스 잔여나 목소리 손상이 생길 수 있습니다.
추출본을 먼저 듣고 사용 여부를 선택하세요. 한 사람의 보컬이 선명하지 않으면
청취 확인을 체크하지 마세요. 음높이 비교는 참고용 추정치이며 정답/기법 점수가 아닙니다.

자동검증: Android 빌드, 관련 JVM 73건, 실제 ONNX 추론/Python 대조 1건(2가수),
화면 동작 모의검사 18그룹, APK 자산/모델해시/동일서명 검사.
PC에서 실제 가창+합성반주 13초 2개를 검증했습니다. 상용곡·교사 품질검수는 아닙니다.
실제 Android 설치/업데이트/데이터 복원·코덱·추론메모리·발열·처리시간·청취는 미검증입니다.
폰의 실행 가능성과 보컬 품질을 PC 시험으로 보장하지 않습니다.
Gemini Flash/Live 코치는 이번 버전에 없으며 기존 기능 개발 이후 마지막 단계입니다.
