VocalMate 0.11.1-dev — 가창 파일 우선 비교·마이크 구간 집중 코칭
Android 8 이상. 기존 앱을 삭제하지 말고 업데이트하세요. 동일 서명, 버전 코드22.

이번 수정: 쏭즈 강사 추가. 강사별 검색·주제 분류·24개씩 더 보기·공식 재생목록·유튜브 계정으로 시청 연결. 영상 목록에는 일반 채널 영상도 포함하며 교육 관련 분류는 제목 기준입니다. 회원전용 표시만으로 목록에서 제외하지 않습니다.
API 키 입력칸 바로 아래에 저장 중/저장 완료/저장 실패 표시. 저장 후 다시 읽어 일치해야 완료 안내. 입력칸을 비우는 이유 명시.

사용 순서
1. 노래부르기에서 기준곡 파일 또는 공개 유튜브 음원 링크를 가져옵니다(최대30분/100MB).
   기기에 기준곡을 보존하고 전곡 관측값을 한 번 분석·저장한 뒤 처음부터 끝까지 재생합니다.
   중지/화면이동 시 자동 재생은 멈춥니다. 전체 듣기·분석 버튼으로 다시 시작할 수 있습니다.
2. 내 가창 파일 첨부가 기본입니다. 첨부하면 저장된 기준곡과 로컬 비교를 시작합니다.
   반주 혼합이면 정답 음정 점수를 만들지 않으며 보컬 추출/청취 확인 후 참고 비교를 제공합니다.
3. 파일이 없으면 파형에서 구간을 선택하고 선택 구간 마이크로 부르기를 누릅니다.
   기준 구간 듣기→준비→마이크 녹음 후 저장된 해당 녹음의 집중 비교 버튼을 누릅니다.
   마이크 녹음은 선택한 구간과만 비교하며 전곡 가창과 성과를 섞지 않습니다.
4. 설정→Gemini 보컬 코치에서 API 키 저장, AI 사용·음성전송 동의·무료 프로젝트 확인 후 AI 설정 저장.
   Flash와 Live는 한 키를 사용합니다. 키 변경 때 무료 프로젝트 확인은 해제됩니다.
   연결 검사는 키와 모델 조회 검사이며 실제 음성 호출/무료 잔여량 검사가 아닙니다.
5. 기준곡 AI 분석 또는 내 가창 파일 AI 비교 코칭을 누르면 실제 음원을 Google에 전송해 분석합니다.
   마이크 구간 비교 시 기준곡 전체+녹음 구간을 전송하고 시간 범위를 지시합니다. 기준곡 전송을 구간만으로 자르는 기능은 아닙니다.
   기준곡 AI 의견은 저장·재사용합니다. 비교 요청에는 두 실제 음원을 첨부해 다시 대조합니다.
   자동 코칭을 켠 경우 기준곡 전체 듣기 완료/가창 파일 첨부/녹음 저장 뒤 요청합니다. 기본은 꺼짐입니다.
6. Flash 결과로 Live 코칭: 실시간 질문·발성 대화(이어폰 권장), 최대10분. 화면이동/백그라운드/중지 시 종료.
   Live 대화 Flash로 교차 정리는 대화 전사를 검토하는 순차 코칭이며 새 음성 재청취라고 표시하지 않습니다.
   두 모델의 동시 자동 호출이나 유료 모델 대체는 없습니다. API 키는 Android Keystore로 암호화해 백업 제외 저장합니다.
   무료 프로젝트 여부/무료 잔여량/청구액은 앱이 판별하지 못하므로 Google AI Studio에서 직접 확인하세요.
   무료 API 자료 사용은 Google 정책을 따릅니다. 서버 임시 음원은 분석 뒤 삭제 요청하며 실패를 안내합니다(최대48시간 보관).

기존 기능 유지
13강사·영상 목록3,739개·공식 재생목록132개·프로필·유튜브 공식 계정 연결, 악보/피아노 음정그래프, 전문 가수 모음 시범,
프로필/사진, 캘리브레이션, 청음·리듬·녹음·노래 보컬추출. 저장 데이터 삭제 시 프로필·사진·API 키는 유지합니다.
유튜브 가져오기는 영상의 오디오 트랙을 사용하며 로그인·유료·실시간 영상은 지원하지 않습니다.
영상 자체에 편집되어 포함된 광고/멘트까지 자동 삭제하는 기능은 아닙니다.
