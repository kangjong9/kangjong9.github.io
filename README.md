# 주인아저씨의 놀이방 — GitHub Pages
대상 주소: https://kangjong9.github.io/

## 게시 조건
1. GitHub Settings > Account > Change username에서 kangjong9로 변경. 이름 사용 가능 여부는 설정에서 최종 확인.
2. Public 저장소 kangjong9.github.io 생성.
3. 이 폴더의 내용(index.html과 assets 등이 저장소 루트에 위치)을 업로드.
4. Settings > Pages > Deploy from a branch > main / (root) > Save.

## 기능
메인 화면과 테마는 GitHub Pages에서 제공한다.
떠든 사람은 기존 Sites 서버의 /#guestbook으로 이동하며 기존 게시글을 사용한다.
관리자 로그인은 기존 Sites 서버의 /admin으로 이동한다.
게시판/관리자 화면에서는 기존 chatgpt.site 주소가 보인다. 기존 Sites 서버를 삭제하면 해당 기능은 동작하지 않는다.
서버 소스, 환경변수, 인증정보, DB는 이 공개 폴더에 포함하지 않는다.
